# Original session interchange fixtures

The five scalar/PCM archives are independently generated by
`Tools/Sessions/generate_fixtures.py`, using Python JSON, explicit little-endian
packing and SHA-256. The generator reads no Swift exports, recordings, external
reference output or network data. All identifiers, values and acquisition metadata
are synthetic. Redistribution follows the project's pending license decision.

- `scalars-v1.hvps`: complete audio-free archive, fifteen scalar results, every
  unavailable reason, confidence/warnings, bounded intermediate values, exact source
  clocks above 2^54, near-maximum UInt64 host clocks, two continuity origins and a
  known acquisition gap with discarded pending work.
- `partial-v1.hvps`: the same records with a sealed partial acquisition status.
- `interrupted-v1.hvps`: the complete archive truncated seven bytes before its end;
  strict import fails and explicit recovery yields only the verified prefix.
- `embedded-pcm-v1.hvps`: four scheduled RMS results under a complete pinned level
  profile, their dependency/coverage/batching metadata, a replay plan and an original
  108-byte PCM16 WAVE file. It contains 32 mono samples at 16 kHz, each 8192/32768;
  RMS is exactly 0.25 for each nonoverlapping eight-sample window. Two chunks split
  the container at byte 31 to test non-frame-aligned archive IO.
- `omitted-pcm-v1.hvps`: the same scheduled measurements, original-media reference
  and replay plan with explicit omission and no audio chunks.
- `calibration-v1.hvps`: a separately generated public Swift API fixture containing
  64 labelled takes, masks/exclusions, 14 fitting and 50 held-out assignments,
  fabricated analysis/validation contract data, and two inspection-only target
  documents. One uses the current fitter; one declares unsupported fitter version
  99. The CPPS identity scale and full reference profile are retained. No audio or
  activation capability is embedded.

`manifest.json` pins each archive's bytes and SHA-256. Native tests check meaning
independently and re-encode every complete archive byte for byte. The Python tests
audit framing/seal counts and original PCM separately, with corruption controls.
The imaginary decoder runtime is retained as provenance, not substituted for the
runtime that actually replays the recording.

`calibration-manifest.json` separately pins the calibration archive, profile,
dataset, split, target and independent `PersonalTargets/fitting-reference.json`
input. `SyntheticCalibrationFixture.swift` constructs it with public native APIs;
it is not an independent wire-format implementation. Python framing checks and
cross-platform native inspection check its retained meaning. The fabricated
validation claim establishes no DSP correctness or target effectiveness.

Generate candidates into a new directory, then review comparisons before changing
goldens and their entries in `Configuration/provenance.json`:

```sh
python3 Tools/Sessions/generate_fixtures.py --output .build/session-candidates
swift run --package-path Examples/SessionWorkflow SessionWorkflow \
  --generate-calibration-fixture \
  --reference Tests/HDXLVoiceProcessingTests/Fixtures/PersonalTargets/fitting-reference.json \
  --output .build/session-calibration-candidates
python3 -m unittest discover -s Tools/Tests -p 'test_session_fixtures.py'
swift test --filter sessionCanonical
```

These fixtures establish software interchange behavior, not physical capture,
perceptual voice quality, personal-target effectiveness or recording consent.
